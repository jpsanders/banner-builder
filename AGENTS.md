# AGENTS.md

Instructions for AI coding agents working on banner-builder itself. To use the tool, read
`skills/banner-builder/SKILL.md` or run `banner-builder guide`.

## Commands

```sh
make init-dev     # install the package and the development tools into the active environment
make format       # apply black and isort
make checks       # every check CI runs, in CI's order; run it before you say a change is done
make man          # rebuild the man page and the packaged manual after editing docs/MANUAL.md
make examples     # redraw docs/examples from the starter config
```

Use Python 3.15 for development; the package supports 3.14 and later.

## Layout

```text
src/banner_builder/api.py      what the CLI and the MCP server both call; returns plain data, never prints
src/banner_builder/cli.py      the command line; human output and --json
src/banner_builder/mcp.py      the MCP server on stdio, no dependencies
src/banner_builder/layout.py   sizes, rows and the checks
src/banner_builder/render.py   SVG with embedded font subsets, PNG through resvg
src/banner_builder/data/       MANUAL.md and banner-builder.1, generated by make man
docs/MANUAL.md                 the one source for the guide and the man page
```

## Rules

- mypy runs in strict mode, docstrings use the Sphinx style, imports are absolute, lines stop at 120 characters.
- A new command or option goes into `api.py` first, then `cli.py`, then `mcp.py` if agents should have it, then
  `docs/MANUAL.md` and `make man`, then `CHANGELOG.md`.
- Never put a real person's banner words, name, site or colours in tests, examples or docs. Use placeholder text.
- The tool makes no network requests. Keep it that way.
- Tags carry the bare version, `1.2.0`, never `v1.2.0`.
